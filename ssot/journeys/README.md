# Journeys - provisional

A **journey** is an end-to-end path a person takes through the product, composed of
several use cases. It sits one level above [use-cases/](../use-cases/README.md): a use
case is one actor, one goal, one sitting; a journey is what joins them, and the
relationship is many-to-many in both directions.

## This folder is parked, not adopted

The layer is **not part of the SSOT structure**. Deliberately:

- It is absent from the folder table and the index in [SSOT](../README.md).
- It is absent from the chain in [Traceability Map](../overview/traceability-map.md).
- No use case links up to it, and no generator writes a back-reference down to it.
- No format page defines what a journey page asserts or what it must not duplicate.

Whether the layer exists, where it sits, and what a journey page owns are open
questions to be settled together rather than by whoever writes the next page.

Until then: the page here is **a record of work, not a specification**. Do not cite it
as a source of truth over the use cases it names, and do not copy its shape into a
second journey.
