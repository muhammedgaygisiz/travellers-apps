- Product intent
  - Keep map exploration stable while live Bite updates arrive.
  - Do not yank the user's camera back to the full marker set after they have already panned or zoomed.
- Scope
  - Preserve the initial automatic marker fit when the map first loads.
  - Preserve current camera position after subsequent marker updates.
  - Reset auto-fit behavior only when the marker list becomes empty.
- Implementation
  - `libs/bite-tribe-common/map/src/lib/map/map.component.ts` tracks whether the map has already auto-fitted markers.
  - Marker updates still refresh the marker cluster.
  - Camera fitting is skipped after the first successful fit so live stream updates do not jump the viewport.
