# CLAUDE.md

## Purpose

This file is a Claude Code entrypoint for the shared repository agent contract.

The source of truth is not Claude-specific. Follow `AGENTS.md` and the SSOT pages under `ssot/pages`.

## Required Start

1. Read `AGENTS.md`.
2. Read `ssot/pages/SSOT.md`.
3. Read `ssot/pages/Agent Operating Contract.md`.
4. Use `ssot/pages/Traceability Map.md` to connect the request to product, domain, use case, epic, architecture, implementation, testing, and release context.
5. Follow `ssot/pages/Spec To Code Workflow.md` for implementation work.
6. Follow `ssot/pages/Feature Delivery Workflow.md` for normal issue-to-merge work.
7. Follow `ssot/pages/Release Workflow.md` for Sunday release work.

## Claude-Specific Note

Do not treat this file as a separate workflow. It only points Claude to the model-agnostic SSOT contract so Codex, Claude, and other coding agents work from the same operating model.
