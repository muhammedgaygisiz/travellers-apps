- Description
  - \# Epic: Nx and dependency migration
  - Execute the staged toolchain migration defined in the SSOT without combining unrelated Nx, Angular, native, backend, E2E, and visual-regression risk.
  - \#\# Goal
  - Reach a supported and reliable Nx 23 / Angular workspace, remove obsolete Nx plugin constraints, align Node and Capacitor tooling, and complete Angular 22 only when its compatibility prerequisites are satisfied.
  - \#\# Roadmap source
  - SSOT: `Current State - Nx And Dependency Migration Roadmap`
  - Start date: 18 July 2026
  - Initial release-candidate scope: Phases 0 to 2
  - Angular 22 is not a release-candidate prerequisite.
  - \#\# Decisions
  - Playwright is the only E2E framework; remove the legacy Cypress project rather than migrating it.
  - Use upstream `oblador/loki` directly; remove `nx-loki` and its inferred targets.
  - Pin local and CI Node.js to the same supported Node 24 release.
  - Upgrade all official `nx` and `@nx/*` packages in lockstep.
  - Move through latest Nx 22.7 before Nx 23.1.
  - Keep Angular 21 and TypeScript 5.9 during the Nx 23 migration.
  - Upgrade `@nxext/capacitor` to v23 with Nx 23.
  - Keep Capacitor, Firebase, Stylelint, and other independent majors in separate validated changes.
  - \#\# Success criteria
  - Cypress and `nx-loki` are removed with required coverage/workflows preserved.
  - Nx graph and reporting commands complete reliably.
  - Nx 23.1 and official plugins are aligned, including `@nxext/capacitor@23`.
  - Playwright, Storybook, direct Loki, Jest, Firebase Functions, and native validation gates pass.
  - Angular 22 and TypeScript 6 land only after stable NgRx 22 and all declared compatibility prerequisites are available.
  - SSOT known issues and release state reflect any remaining exceptions.
  - \#\# Validation rule
  - Each child issue must pass its own focused gate and `git diff --check`. Do not start the next migration phase until the previous phase is green.

- Outcome
  - Complete on 24 August 2026. All eleven sub-issues are closed and every success criterion in the epic body is met.
  - The last one, \#1037, was the only child that could not be scheduled: it declared stable NgRx 22 as a prerequisite, and NgRx 22.0.0 published on 24 August 2026. The workspace side had been ready since Phase 3.
  - Final state: Nx `23.1.0` with every official `@nx/*` package and `@nxext/capacitor@23` on a single generation; Angular `22.1.3` / CLI `22.1.5`; NgRx `22.0.0`; TypeScript `6.0.3`; Node pinned to `24.18.0` in `.nvmrc`, `engines`, and CI; Playwright owning all E2E with Cypress gone; direct `oblador/loki` owning visual regression with `nx-loki` gone.
  - Angular 22 landed with its compatibility shims kept rather than its new behavior adopted, so the version move stayed behavior-preserving. The adoption work those shims defer, together with the other capabilities the epic's upgrades made available but that the codebase does not yet use, is tracked in separate P1 technical issues rather than inside this epic.
  - Serial Playwright E2E, direct Loki visual regression, Capacitor sync, and the Android/iOS device builds were deferred to CI/device runs throughout the epic, because the agent sandbox has no emulators, reference images, `sharp` prebuilt binary, or native toolchains. For the final issue, \#1037, CI closed most of that: [run 2809](https://github.com/muhammedgaygisiz/travellers-apps/actions/runs/32866446626) executed both Playwright suites against the Firebase emulators and the full Loki suite against the committed references, all green. The epic's one standing risk is therefore the native half alone - Capacitor sync, the Android and iOS builds, and the launch-critical device checks - which is carried by the release-candidate charter rather than by this page.
