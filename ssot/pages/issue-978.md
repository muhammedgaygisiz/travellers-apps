- [launch: verify currency prefill edge cases](https://github.com/muhammedgaygisiz/travellers-apps/issues/978) (Issue \#978)
- Status
  - Created as the follow-up to [[issue-909]] after currency prefill became the primary solution.
- Roadmap context
  - Phase 1 - Launch Preparation, Week 2.
  - Supports the 17 July 2026 launch-blocking backend milestone by proving the current currency flow instead of adding broader warning UI prematurely.
- Product intent
  - Verify that location-based currency prefill is good enough for launch.
  - Preserve user control when auto-selected currency is wrong.
  - Add extra mismatch warnings only if testing shows the prefill-plus-override flow is insufficient.
- Scope
  - Test normal local Bite creation.
  - Test missing position fallback to preferred currency.
  - Test failed currency resolution without blocking Bite creation.
  - Test position changes, including photo/location changes from another country.
  - Test manual currency override before saving.
  - Test travel, posting-later, and border-region scenarios.
