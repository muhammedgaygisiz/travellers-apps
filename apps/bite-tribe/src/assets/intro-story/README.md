# Intro story video assets

Generated by **dev-only** Remotion (`tools/intro-story-remotion`).

```bash
npm run intro-story:render
# or: cd tools/intro-story-remotion && npm install && npm run render
```

Do not hand-edit these files — re-render from Remotion after composition changes.

Remotion compositions are **stylized fake-UI** matching current intro-story
beats/captions (Find → Share → Tribe → Go). They do **not** pixel-capture the
Angular real-UI stage.

| File            | Beat (current narrative)                    |
| --------------- | ------------------------------------------- |
| `discover.webm` | Feed scroll → Botanic Breeze card settle    |
| `share.webm`    | Create → photo → publish → thumbs-up cheer  |
| `tribe.webm`    | Explorer profile → Follow → Following toast |
| `go.webm`       | Map pin → drawer → Directions               |
