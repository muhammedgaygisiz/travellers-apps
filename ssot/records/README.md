# Records

Closing records for work that is already done: what was found, what was decided, what
changed, what was validated, and what was left open. One page per issue or epic.

**These are history, not specification.** A rule that is still true belongs on the page
that owns it, not here. Nothing in this folder is extended or kept in sync with GitHub -
for the current state of an issue, ask GitHub (`gh issue view <number>`).

They exist because the [Reporting Rules](../overview/agent-operating-contract.md#reporting-rules)
named no destination for a closing report, so it was written into the page the epics
generator had left lying around. Reports written from now on are comments on the issue,
per [Closing Report](../overview/github-issue-format.md#closing-report).

Part of the [SSOT index](../README.md).
