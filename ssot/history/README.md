# History

What happened: accounts of the repository as it was at the time they were written.

**Never the source for a current fact.** A page here can state something that has
since become untrue, and nothing keeps it in sync. What is true now lives on the page
that owns it elsewhere in the [SSOT](../README.md); [Traceability Map](../overview/traceability-map.md)
finds that page.

Read this folder only when the task asks what happened in a past release, test run or
epic. Pages here are not corrected later, and quoted paths in them are exempt from the
`PATH` rule of `npm run check:ssot`; see `Superseded Facts` in
[Agent Operating Contract](../overview/agent-operating-contract.md#superseded-facts).

- [records/](records/README.md) - closing records for issues and epics already done
- [test-runs/](test-runs/README.md) - release-candidate test runs, one per run

The release history is not here: it is the root [CHANGELOG.md](../../CHANGELOG.md).

Part of the [SSOT index](../README.md).
