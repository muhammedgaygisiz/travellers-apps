# Releases

One page per release tag, plus the index.

**This folder is generated.** `npm run generate-full-changelog` rebuilds
[changelog.md](changelog.md) and every `build-*.md` from the git tags, so an edit here is
undone on the next release. Change `tools/generate-full-changelog.mjs` instead.

- [changelog.md](changelog.md) - the index, newest tag last
