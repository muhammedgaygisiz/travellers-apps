- [feat: admin wants to maintain opening hours of an restaurant](https://github.com/muhammedgaygisiz/travellers-apps/issues/795) (Issue \#795)
- Description
  - The admin wants to maintain the opening hours of an restaurant. For that a new component should be introduced.
  - It should be an table with the days of the week in the first column, checkbox if the restaurant is open in the second column, and if it is open the opening hours in the third column.
  - If a day is marked as open, in the third column the user has an add button. Clicking on it adds a time-range component with the beginning hour and the ending hour. The user can add multiple of these time-ranges. When added, a delete button should be shown at the end of the date-range.
  - The strucuture would be something like the following in a pseudo table form:
  - Weekday | Open | Times
  ***
  - Monday | [x] Open | +
  - Tuesday | [x] Open | 10-12 -
  - | | 14-19 -
  - | | +
  - ...
  - The user can enter the opening hours while creating a restaurant or while editing a restaurant. The opening hours will then be shown in the bite-tribe app when the user is on the restaurants page. So the order in the restaurant page in bite-tribe will be:
  - image
  - name + rating
  - description + opening hours
  - distance
  - map
  - ...
